# Master index

Auto-generated dari tree.txt. Regenerate dengan `make index` (lihat `scaffold.bat`).

## Cara pakai

- Cari berdasarkan nama folder: `grep -i "nama" INDEX.md`
- Cari berdasarkan path: `grep -i "path/ke/folder" INDEX.md`
- Sortir: `sort INDEX.md`

## Format

```

NN-slug/           # satu baris per top-level
NN-slug/          # level-2, indent 2 spasi
NN-slug/         # level-3, indent 4 spasi

```

Lihat `tree.txt` untuk path lengkap.
